# Registre des sources

Consultation de cette édition: **3 août 2026**, heure de Bruxelles. Les URL sont dédupliquées. « Non publiée » signifie que la page n’affiche pas de date exploitable. Les pages dynamiques peuvent évoluer sans changer d’URL.

## Limite de vérification propre à l’exécution du 3 août 2026

Lors de cette exécution, l’accès réseau **direct** (WebFetch/curl) à la plupart des domaines officiels a été **bloqué par la politique de l’environnement** (réponses 403 au niveau du proxy) : notamment `openai.com`, `developers.openai.com`, `ai.google.dev`, `azure.microsoft.com`, `aws.amazon.com`, `docs.x.ai`, `docs.mistral.ai`, `ibm.com`, `cursor.com`, `docs.perplexity.ai`, `api-docs.deepseek.com`, `docs.cohere.com`, `help.aliyun.com`, `huggingface.co`, `replit.com`, `docs.z.ai`, `platform.moonshot.ai`, `ecb.europa.eu`, `ec.europa.eu`, `edpb.europa.eu`.

Seuls `github.com` (plans GitHub Copilot, dépôts Moonshot) et `platform.claude.com` ont pu être lus directement. Pour tous les autres, la vérification a été faite par **recherche web restreinte aux domaines officiels** (extraits des pages officielles) recoupée par des sources secondaires réputées et par ≥2 agrégateurs indépendants pour chaque tarif. Les chiffres n’ont donc **pas** été lus ligne à ligne sur les grilles officielles cette fois. Chaque donnée reposant uniquement sur une source secondaire est marquée dans les fichiers d’analyse. Pour l’édition suivante, il est recommandé d’autoriser l’accès direct à ces domaines ou de contrôler manuellement les grilles bloquées.

## Sources non retenues

Les agrégateurs de prix, billets Reddit et comparatifs non reproductibles n’ont pas servi à fixer les caractéristiques. Ils ont uniquement orienté des vérifications sur les pages officielles. Les dates « dynamique » indiquent une page vivante sans date de version stable. Pour cette exécution, l’accès direct étant bloqué (voir la limite ci-dessus), plusieurs tarifs reposent sur des extraits officiels recoupés par des sources secondaires ; ils sont signalés comme tels dans les fichiers d’analyse et devront être recontrôlés sur les grilles officielles à la prochaine exécution.
